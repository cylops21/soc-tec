**Search 3: limits.conf setting (CVE-2026-76264)**

This one needs a configuration change after upgrading.

```spl
| rest /servicesNS/nobody/system/configs/conf-limits/lookup splunk_server=*
| eval cve_76264_config=if(scripted_lookup_raw_write_enforcement="block","Set correctly","MISSING - set to block")
| table splunk_server scripted_lookup_raw_write_enforcement cve_76264_config
```

If a node returns no row or an empty value, confirm on that host with `splunk btool limits list lookup --debug`.

**A few caveats:**

- **SVD-2026-1002** (the internal hardening advisory) is fixed by the same versions. If Search 1 shows `Patched` for the standard group, those are covered too.
- **CVE-2026-76266** only matters if you install or upgrade with RPM/DEB packages. Tarball installs aren't exposed through that path.
- **Nodes the search head can't reach** won't appear in any of these results. Check standalone forwarders and similar hosts directly with `splunk version`.
